### #18 — `idea-card.css`

**Scope:** `find-animation-opportunities` + `emil-design-eng`

**Context:** Card rendered inside `ideas-grid.html`'s `.grid-3`. Per product requirement, an expanded card must **float above neighboring grid cells** (with `z-index` + elevated `box-shadow`) rather than push the grid row taller. So `.idea-card-wrapper` is **not** dead deck residue — it is the load-bearing float-above-grid mechanism: the wrapper is the grid item (with fixed `min-height`, so the grid cell never changes height), and `.idea-card` inside it is `position: absolute` so it can grow downward past the wrapper bounds without disturbing neighbors.

**Findings:**

- `.idea-card-details` — expanded via `@if (expanded())` in template; block appeared instantly with no transition. Occasional frequency, purpose: preventing a jarring change. → ✅ Fixed — switched to always-rendered `display: grid; grid-template-rows: 0fr ⇄ 1fr` + `opacity` with class-driven entry, both expand and collapse animate via `var(--transition-standard)`
- **Specificity bug found and fixed** — initial attempt put a standalone `.idea-card-details { display: grid }` block at file bottom (specificity `0-1-0`); it was overridden by the nested `.idea-card .idea-card-details { display: flex }` rule above it (specificity `0-2-0`), so the grid-rows trick never took effect. → ✅ Fixed — merged into the nested block, standalone block deleted
- **Border/padding on grid container bug found and fixed** — `border-top`/`padding-top` were on the grid container, so they would have "stuck" when `grid-template-rows` collapsed to `0fr` and caused a visible jump. → ✅ Fixed — moved `border-top`/`padding-top`/`gap` onto the inner wrapper `idea-card-details-inner`, kept grid container "clean"
- **Two required grid-rows guards added** — `overflow: hidden` on `.idea-card-details` (without it, content "escapes" the collapsed `0fr` row and looks un-collapsed); `min-height: 0` on `.idea-card-details-inner` (flex children default to `min-height: auto`, which can prevent them from shrinking below their content's natural height inside a grid item)
- `.idea-card-wrapper` — first audit pass wrongly removed this block as "dead deck mechanics". Reinstated: it is the intentional float-above-grid mechanism (see Context). `min-height: 400px` is an over-estimate placeholder — needs tuning after measuring the actual closed-card height in DevTools
- `.idea-card` inside wrapper — `position: absolute; top: 0; left: 0; right: 0; width: 100%` with **no `bottom`** so the card can grow downward past the wrapper bounds when expanded. `:has(.idea-card-details.expanded)` raises `z-index: 10` + `box-shadow: var(--shadow-elevated)`
- **`z-index` transition is intentional — do not simplify.** `z-index 0s linear 350ms` on the base (delayed) and `z-index 0s linear 0s` on `.expanded` (immediate): the card rises above neighbors the instant it starts opening, but only drops back after its box-shadow/transform teardown finishes (350ms later), so the closing card does not visually "tuck under" neighbors mid-animation. This syntax is legal, load-bearing, and must not be "fixed" by future refactors/linters
- `.primary-btn` (toggle) `:active` press feedback — out of scope; `.primary-btn` is a global element, its `:active` belongs in `_buttons.css`
- `.score-badge` color transition — rejected: badge is rendered once per idea, no in-place state change to animate
- `.tag` stagger — rejected: information-dense; handled by global `stagger` class if desired, out of scope for this file

**Applied:**

- `idea-card.css` — kept `.idea-card-wrapper` (re-added with the corrected `.idea-card` positioning: `top/left/right` + `width:100%`, **no `bottom`**) and the original `:has(.expanded)` `z-index`/`box-shadow` transitions unchanged · restructured `.idea-card .idea-card-details` from `display: flex` to `display: grid; grid-template-rows: 0fr; opacity: 0; overflow: hidden` with `&.expanded { 1fr; opacity: 1 }` and `var(--transition-standard)` on both properties · added `.idea-card-details-inner` flex column carrying `border-top`/`padding-top`/`gap`/`min-height: 0` (the inner wrapper, not the grid container)
- `idea-card.html` — replaced `@if (expanded()) { <div .idea-card-details>… }` with always-rendered `<div .idea-card-details [class.expanded]="expanded()"><div .idea-card-details-inner>…</div></div>`

**Known follow-up:** `min-height: 400px` on `.idea-card-wrapper` is an over-estimate. After opening the ideas page in DevTools, measure the actual closed-card height and tune the value down to remove any dead gap below closed cards.

**Verification:** `npx ng build` — clean (only pre-existing budget warnings from #16) · mojibake scan clean · Hebrew text in `idea-card.html` preserved
